# 질문에 날개를 달다 · 3D 디지털 전시관

남산중학교 「질문하는 학교」 성과공유회 전시를 걸어서 둘러보는 3D 웹 전시관입니다.
외부 라이브러리 없이 순수 WebGL로 만들었습니다.

디지털 아카이브에 포함할 때는 이 폴더를 저장소 최상위의 `3d-expo/`에 두고, `../index.html`을 통해 2D 디지털 아카이브로 돌아갑니다.

## 실행 방법
`index.html`을 바로 더블클릭하면 브라우저 보안 정책 때문에 사진이 안 보일 수 있어요.
아래처럼 간단한 웹 서버로 여세요.

```bash
cd namsan-3d-expo
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 열기
```

Firebase Hosting, GitHub Pages, Netlify 같은 정적 호스팅에 폴더째 올려도 됩니다.

## 파일 구성
- `index.html`: 화면, 3D 엔진, 게임 로직이 모두 들어 있는 파일
- `img/b/`: 중앙 화단 보드 5장 (정면으로 편 사진, 제목 스티커는 투명 배경, 학생 얼굴 흐림), `*_m.jpg`는 살펴보기 창용
- `img/t/`: 탁자 위 아크릴 안내판·파일철 페이지·활동지·M&Q 카드, 또래약국·질문해봐 배너, 주제 카드, QR
- `img/p/`: 살펴보기 창에 뜨는 실제 사진 (이름·얼굴 흐림)
- `img/cards/`, `card_atlas.jpg`, `sign_*.png`: 질문 나무 카드 35장과 안내판
- `img/tex/`: 재질 이미지 (헤링본 마루, 테라조, 천장 텍스, 집성목, 베이지 패널, 창문, 식물, 그래비트랙스 판)
- 그 밖의 `img/*.jpg`: 날개 벽화, 현수막, 게시판, 예술 보드 등

## 고치기 쉬운 곳 (index.html 안)
- `CARDS`: 질문 카드 35장의 주제, 카드 번호, 질문 문장 (순서는 cards/c01~c35와 같아요)
- `CATC`: 카드 주제별 색
- `TREE`: 질문 나무 위치
- `QUIZ`: 숨은 깃털 6개의 위치, 문제, 보기, 정답, 힌트
- `INFO`: 전시물 살펴보기 창의 제목, 사진, 설명
- `buildScene()`: 전시물 배치 (단위는 미터. `RX0`·`RX1`은 복도 바깥벽·동쪽 벽, `PX`는 기둥 줄, `DZ0`·`DZ1`은 방화문)
- `BD`: 화단 보드 6개의 순서와 방향, `INFO`: 살펴보기 설명

카드를 바꾸거나 늘리려면 `cards/` 이미지와 `card_atlas.jpg`를 같은 순서로 바꾸고 `CARDS` 목록을 고치면 돼요.

## 조작
- PC: W/A/S/D 이동, 마우스 끌기로 둘러보기, E 살펴보기, V 시점 바꾸기, Shift 달리기
- 휴대폰: 왼쪽 화면 끌기로 이동, 오른쪽 화면 끌기로 둘러보기, 둥근 버튼으로 살펴보기
- 질문 나무: 카드를 화면 가운데 점으로 겨누면 그 카드가 커지고, E(또는 버튼)로 크게 볼 수 있어요. 카드를 겨누지 않으면 35장 모아보기가 열려요.

## 참고
- 나만의 질문 기록과 읽은 카드 표시는 각 기기의 브라우저(localStorage)에만 저장되며 다른 이용자에게 공유되지 않습니다.
- 글꼴(Jua, Gowun Dodum)은 Google Fonts에서 불러오며, 인터넷이 없으면 기본 글꼴로 보입니다.
