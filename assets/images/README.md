# 활동 사진 폴더

활동 사진을 영역별 하위 폴더에 저장한 뒤 해당 `data` 파일의 `images` 배열에 경로를 등록하세요.

- `school/` — 질문하는 학교
- `student/` — 질문하는 학생
- `lesson/` — 질문하는 수업
- `teacher/` — 함께 성장하는 교사
- `naskin/` — N-ASKIN 관련 이미지

파일명은 영문 소문자, 숫자, 하이픈을 사용하면 관리하기 편합니다.

예시: `school/question-wings-main.jpg`, `school/quest-trip-01.webp`
